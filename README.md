This is the project repository for the noodle engine and the RedAngel game project. This engine is being built to support 2D game development.

Current Features:
- Data Driven Asset Cooking and Serialziation (transform, texture, and shader cooking)
- Actor / Component Architecture
- 2D Rendering with Direct3D 12
- Resource Management
- Input Management
- Event Management
- Player Controller
- Sprite sheet animations

To Build and Run
- Build the RA.slnx solution in the debug configuration in Visual Studio 2026
- Run RedAngel/CookAllScenes.bat (requires the noodleCooker debug exe)
- Run the RedAngel project
- Should be able to move the sprite around the window with WASD
